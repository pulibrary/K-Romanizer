# K-Romanizer 2
> A Windows-based romanization and cataloging support tool designed primarily for librarians and researchers working with Korean-language materials, with optional AI-assisted support for ALA-LC Japanese romanization.

### Romanization Standards

K-Romanizer 2 supports:

[**ALA-LC Korean Romanization**](https://www.loc.gov/catdir/cpso/romanization/korean.pdf), widely used for Korean-language cataloging.

[**Revised Romanization of Korean**](https://korean.go.kr/kornorms/regltn/regltnView.do?regltn_code=0004#a) (한국어 로마자 표기법), the official romanization standard in the Republic of Korea.

> **Note:** ALA-LC romanization requires proper Korean word division. Users should be familiar with the ALA-LC Korean Romanization guidelines, as incorrect word division may result in inaccurate romanization.

### Quick Start

1. [**Download K-Romanizer 2**](https://github.com/pulibrary/K-Romanizer/releases/latest/download/K-Romanizer2.exe).
2. Place `K-Romanizer2.exe` in a folder of your choice. No installation is required.
3. Run the program. On first launch, K-Romanizer 2 automatically downloads the latest dictionary file. An internet connection is required for this initial download and subsequent dictionary updates.

### What's New in K-Romanizer 2

- Redesigned modular romanization engine
- Expanded Hancha support (~6,000 → ~20,000 characters)
- Faster long-text processing
- Automatic dictionary updates
- Excel batch processing and error reporting
- Sanskrit romanization
- Optional AI-assisted Korean word division and Japanese romanization

### Troubleshooting

K-Romanizer 2 is digitally signed by the Trustees of Princeton University to verify its source. If Windows or your institution's security software blocks or flags `K-Romanizer2.exe`, please consult your local IT staff about allowing the program to run on your computer.
